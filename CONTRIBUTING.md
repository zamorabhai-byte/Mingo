# Contributing to Mingo

First off — thank you for considering contributing to Mingo! 🎉

Mingo is a **minimal** messaging app, and we want to keep it that way. Please
keep this philosophy in mind with every contribution.

---

## 🧭 Code of Conduct

Be kind, be respectful, and assume good intent. We're all here to build
something clean and useful.

---

## 🐛 Reporting Bugs

Before opening a new issue, please:

1. **Search existing issues** to avoid duplicates
2. **Check the [Roadmap](./README.md#-roadmap)** — it may already be planned
3. **Use the bug report template** if available

When reporting, include:

- Your OS and device
- Steps to reproduce
- Expected vs actual behavior
- Screenshots or logs (if applicable)

---

## 💡 Suggesting Features

Mingo values **subtraction over addition**. Before suggesting a feature, ask:

> "Does this make the app simpler, or just bigger?"

Open an issue with the `enhancement` label and describe:

- The problem you're solving
- Why the current behavior is insufficient
- How it fits the minimal design philosophy
